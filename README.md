## 更新列表

- 2026/11/02
  1. 编码器旋转现可通过标准 ZMK Studio 改键。左侧拇指按键下方新增两个虚拟键：左为逆时针，右为顺时针。默认层分别为音量减和音量加，其他层默认继承，可逐层修改。
  2. 采用 [gmk70_firmware](https://github.com/skyser2003/gmk70_firmware) 的虚拟键思路，每格旋转产生普通按键的按下和释放事件。刷新左半键盘固件，重新连接 Studio，选择层、修改虚拟键并保存即可。原有实体按键位置编号保持不变。

- 2026/10/29
  1. 移除了 Q/S/Z 软关机组合键，避免这些按键在韩文 Semo-e 等同时输入方式中产生延迟。此更改只需刷新左半键盘固件。
  2. 关机时，按住拇指区的第 2 层切换键，再按住物理 `.` 键 2 秒。按一次复位开关即可唤醒键盘。

- 2024/12/21
  1. 增加zmk-studio支持（只需要刷新左手即可使用）。
- 2024/10/24
  1. 修改供电模式，功耗降低。
  2. 修正RGB供电自动关闭的功能。
- 2025/3/30 增加睡眠进入时间1小时  增加防抖时间 优化睡眠后功耗 
- 2025/8/22
  1. 增加了便于携带外出的软关机功能。原 Q/S/Z 快捷键已于 2026/10/29 移除，请使用上方说明的第 2 层快捷键。按一次复位开关即可唤醒键盘。
  2. 这个月，我还更新了矮轴版本sofle和corne的外壳。框架和底板加厚了，复位开关的开口也进行了调整，可以轻松按下复位开关。目前，我们仍在构思如何设计带有倾斜支架的外壳。如果您仔细检查过 PCB，您会注意到有用于扩展 IO 的预留接口。不知道有没有人能够使用它们，我会尝试一下！
  3. 右侧键盘屏幕上的GIF动画被移除，这将显著降低右侧键盘的功耗。

-2026/6/22 键盘支持DYA STUDIO改键了中文用户联系店主索取中文版DYA STUDIO安装包。这个上位机软件改键比ZMK studio更好用。

### 固件发布

可在 [GitHub Releases](https://github.com/skyser2003/zmk-sofle/releases) 下载固件。
将需要发布的提交推送到 `release` 分支后，GitHub Actions 会先运行测试并构建三个固件，全部成功后再发布。
首次版本为 `v0.1.0`，之后的新提交自动递增最新版本的补丁号。重复运行同一已发布提交时保留原有版本和文件。
首次发布包含 Q/S/Z 输入延迟修复，以及可在 Studio 中修改的编码器旋转按键。

左半键盘使用 `eyelash-sofle-left.uf2`，右半键盘使用 `eyelash-sofle-right.uf2`。
`settings-reset.uf2` 仅用于恢复操作，会清除已保存的设置和配对信息；`SHA256SUMS` 提供校验值。
发布最新 main 提交的命令：`git push origin main:release`。
